# Сайт Татьяны Чаплыгиной

Одностраничный сайт психолога, сексолога и секс-коуча Татьяны Чаплыгиной (Москва, онлайн). Главное действие посетителя – написать в Telegram, чтобы записаться на консультацию. Акцент на мужскую аудиторию, женщины и пары – полноценные направления.

## Стек
Чистый HTML/CSS/JS, без сборщика и фреймворка.
- Плавный скролл: Lenis (`js/vendor/lenis.min.js`, взят из проекта EROTRAVERSE)
- Анимации: vanilla JS + IntersectionObserver
- Шрифт: Inter с оптическим размером (Google Fonts), в крупных кеглях работает как Inter Display

## Запуск
Статический сайт, сборки нет. Локальный сервер из корня проекта:
```bash
python -m http.server 5178
```
Открыть http://localhost:5178/

## Структура
```
index.html        – сайт (появится после выбора первого экрана)
sketches/         – наброски вариантов (первый экран и др.)
css/tokens.css    – цвета, шрифты, отступы
css/base.css      – сброс и базовые стили
js/               – скрипты, js/vendor – сторонние библиотеки
assets/img/       – изображения
```
